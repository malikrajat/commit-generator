## Report an issue

Open an issue at:

`https://github.com/malikrajat/commit-generator/issues`

Include:

- IDE name, version, and build number.
- Plugin version.
- Operating system.
- Provider and model id (never the API key).
- Steps to reproduce.
- Expected and actual behavior.
- Diagnostics output from **Commit Generator: Show Diagnostics** and any metadata-only log lines.

Do not post API keys, private source code, raw diffs, or full prompts in a public issue.

## Security reports

Use a private advisory:

`https://github.com/malikrajat/commit-generator/security/advisories/new`

Do not open a public issue for a vulnerability.

## Feature requests

Open an issue with the problem, the proposed behavior, and how it fits the safety model. Note
whether it affects the commit-panel action, the tool window, or both.

## Response expectations

This is a community-maintained project. Issues are reviewed as time permits. Security reports
are prioritized. There is no paid support contract.
